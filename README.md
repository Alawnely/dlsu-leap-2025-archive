# DLSU LEAP 2025 Archive
A web archive for the DLSU LEAP 2025 website, preserving functionality for future reference.

## 🔗 Original Links
- Front-end: [https://dlsucso-leap.com/](https://dlsucso-leap.com/)
- Back-end: [https://api.dlsucso-leap.com/](https://api.dlsucso-leap.com/)

## 📖 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
  ```bash
  git clone https://github.com/Alawnely/dlsu-leap-2025-archive.git
  cd dlsu-leap-2025-archive
  ```

2. Install dependencies:
  ```bash
  npm install
  ```

### Running the Application

Start the development server:
```bash
npm start
```

The application should now be running at [http://localhost:46635](http://localhost:46635)
